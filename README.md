## Project Description
This project is a server-side web app for an online cookbook. It allows uers to browse and search for recipes, view recipe details, and manage their own recipe collection. 

## AI Use
- ChatGPT — used for guidance with setting up MAMP
- ChatGPT — generated an initial schema.sql structure based on the provided recipe data in excel. I reviewed and modified the schema to match the project structure and course conventions.
